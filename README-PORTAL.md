# LEXO RUTA SEGURA

Portal estático para GitHub Pages.

**Propósito visible:** Prevención, actuación y respaldo empresarial frente al acoso, la violencia y la discriminación laboral, en cumplimiento del Decreto 1040 de 2026 y normas complementarias.

## Publicar en GitHub Pages
1. Descomprime este ZIP.
2. En el repositorio `Nana21082021/Lexo-Ruta-Segura_decreto-1040-2026`, usa **Agregar archivo > Cargar archivos**.
3. Arrastra **el contenido** de la carpeta `Lexo-Ruta-Segura` (index.html, css, js, assets, etc.) al repositorio.
4. Confirma la carga/commit.
5. En el repositorio entra a **Configuración > Pages**.
6. En **Compilación e implementación**, selecciona **Implementar desde una rama**.
7. Rama: `main`; carpeta: `/(root)`.
8. Guarda y espera la publicación.

## Seguridad
No almacenar en GitHub Pages expedientes reales, quejas, nombres, documentos de identidad, información médica, sexual, psicológica ni demás datos sensibles.
